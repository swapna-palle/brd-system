# 5. Guardrails, Agent Authorization & Safety Controls

| Control Area | Implementation | Failure / Attack Prevented |
| :--- | :--- | :--- |
| **1. Deterministic Agent-Level RBAC (PEP)** | Streamlit Session Context (`ui/app.py`) propagates `user_role` claims into n8n's Policy Enforcement Point (`Node 2: Input Guardrail` + `IF Authorized?` + `IF Can Sync Jira?`). `Others` is rejected with `HTTP 403 AGENT_AUTHORIZATION_DENIED` before LLM execution; `Product_Owner` can generate plans but cannot trigger Jira writes or release sign-off; `Engineering_Manager` holds full execution and approval authority. | Prevents unauthorized users from invoking expensive cognitive agents or triggering side-effect tool writes (`Jira Sync`). |
| **2. Input Validation & Prompt-Injection Defense** | `Input Guardrail` (n8n Node 2) enforces `50 <= length <= 25,000` chars, strips control characters, and wraps BRD text inside XML `<brd_document>` delimiters. | Rejects malformed/empty payloads in `0.2s` at zero token cost and isolates untrusted BRD text from system instructions. |
| **3. Schema Compliance & Recovery** | OpenAI `json_object` mode + defensive JSON extraction parsers in n8n Nodes 3, 5, 7a, and Critic Node 4. | Prevents pipeline crashes from markdown code fences or malformed model output. |
| **4. Hallucination & Citation Guardrail** | Mandatory `[CHUNK_ID: <uuid>]` citations checked against `SELECT chunk_id FROM kb_chunks` in Critic Node 4 (`-2.0` Groundedness penalty + `CRITICAL` defect on mismatch). | Blocks fabricated company standards or fake ADR references from reaching Engineering Managers. |
| **5. Scope Creep & Ambiguity Handling** | System prompts prohibit inventing unstated NFR metrics; ambiguous items set `ambiguity_flag: true` and list open clarification questions. | Prevents AI from guessing unapproved SLAs, user counts, or budgets. |
| **6. Confidentiality & PII Protection** | Raw BRD text is never stored in `audit_events`; only cryptographic SHA-256 `input_hash` and MD5 `payload_hash` checksums are persisted, and `.env` / API keys are scrubbed from repo exports. | Ensures auditability without leaking sensitive customer requirements or credentials in logs or Git history. |
| **7. Human-in-the-Loop (HITL) Gate** | Streamlit Studio escalates `AMBER`/`RED` runs with explicit Critic findings and records role-verified `APPROVED_BY_EM` / `REJECTED_BY_EM` decisions in PostgreSQL `audit_events`. | Guarantees human Engineering Manager accountability before external Jira release. |
