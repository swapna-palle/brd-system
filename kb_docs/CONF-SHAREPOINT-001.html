Azure Landing Zone & AKS Standards

Compute and Hosting Tier Selection

Standard .NET 8 Web APIs with fewer than 2,500 requests per second must deploy to Azure App Service (Linux P1v3 or P2v3) with zone redundancy enabled. High-throughput microservices exceeding 5,000 RPS or requiring custom sidecars must deploy to Azure Kubernetes Service (AKS) with KEDA autoscaling.

Network Isolation and Private Endpoints

All production PostgreSQL Flexible Server, Azure Key Vault, Redis Enterprise, and Azure Service Bus instances must disable public internet access and expose private endpoints inside the corporate VNet.
